# Zepto Data & AI Platform - Capstone Project

This repository implements a three-part AI/ML platform for Zepto:
1. **Data Pipeline (`/data_pipeline`)**: Web scraping, data cleaning, baseline GBP to INR currency conversion, SQLite normalized database, and SQL/Pandas analysis.
2. **Analytics Pipeline (`/analytics`)**: End-to-end Titanic dataset profiling, EDA, classification models, imbalance handling, hyperparameter tuning, regression, and pipeline export.
3. **Support Assistant (`/support_assistant`)**: RAG-based AI customer support agent using LangGraph, ChromaDB, Pydantic validation, and FastAPI wrapped in Docker.
